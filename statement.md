\# Project Statement



\## Problem Statement



Basic image processing operations such as resizing, grayscale conversion, noise reduction, thresholding, and edge detection are important tasks in Computer Vision. Performing these operations manually or through separate tools can make the processing workflow less organized for beginners.



This project provides a simple command-line based image processing pipeline using Python and OpenCV. It takes an input image and applies a sequence of common Computer Vision operations, producing separate output images for each stage.



\## Scope of the Project



The project focuses on basic image preprocessing and edge detection techniques. It is designed for educational use and demonstrates how common Computer Vision operations can be combined into a single processing workflow.



The current scope includes:



\* Image resizing

\* Grayscale conversion

\* Gaussian blur

\* Binary thresholding

\* Canny edge detection

\* Saving processed images as output files



\## Target Users



\* Computer Vision students

\* Beginners learning OpenCV

\* Students studying basic image processing

\* Developers who want a simple example of a command-line Computer Vision pipeline



\## High-Level Features



\* Accepts an image path through a command-line argument

\* Resizes the input image

\* Converts the image to grayscale

\* Applies Gaussian blur

\* Performs binary thresholding

\* Detects edges using the Canny algorithm

\* Saves all processed results in the output directory

\* Handles invalid or missing input image paths
